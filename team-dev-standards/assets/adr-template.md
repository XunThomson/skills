# ADR 模板

> 用法：存为 `docs/adr/NNNN-<短标题>.md`，编号连续不复用。单条 <100 行。
> 只写"决策 + 理由 + 被否决方案 + 重评条件"，不写过程叙事。

```markdown
# ADR-<NNNN> <决策标题>

- 状态：提议 / 已接受 / 已弃用 / 被 ADR-<NNNN> 取代
- 日期：<YYYY-MM-DD>
- 决策者：<@who>
- 影响档位：S / M / L
- 关联：<PR / issue / 契约文件>

## 背景
<3 行内：什么问题、什么约束、为什么现在必须定>

## 决策
<一句话：我们决定 X>

## 理由
- <支撑该决策的事实或证据，2–4 条>

## 被否决的方案
| 方案 | 否决原因 | 什么条件下重新考虑 |
|---|---|---|
| <...> | <...> | <...> |

## 后果
- 正面：
- 代价 / 负面：
- 需要后续跟进的项：

## 重评条件（失效信号）
- <出现什么现象就说明该决策需要重评>
```

## 硬规则

- 被否决方案必须写：否则 Agent 会反复提出同一个方案。
- 重评条件必须写：没有失效信号的决策，等于永久假设。
- 决策变更不改旧文件，新建 ADR 并在两者状态里互相指向。
